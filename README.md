NetScope

A lightweight network information lookup tool for Windows.

NetScope retrieves network-related information and displays the results in a simple interface.

Features


- Network information lookup
- Simple and lightweight interface
- No account or registration required

Download

Download the latest version from the "Releases" page.

Installation

1. Open the "Releases" page.
2. Download the latest NetScope executable.
3. Run the downloaded ".zip" file.

If Windows displays a security warning, verify that the file came from the official NetScope repository before proceeding.

Privacy

NetScope is designed with privacy in mind.

Read the "Privacy Policy" (PRIVACY.md) for information about data handling and network requests.

Disclaimer

Use NetScope responsibly and only for legitimate purposes.

NetScope

ابزاری سبک برای دریافت اطلاعات شبکه در ویندوز.

NetScope اطلاعات مرتبط با شبکه را دریافت می‌کند و نتایج را در یک رابط کاربری ساده نمایش می‌دهد.

امکانات

- دریافت اطلاعات شبکه
- رابط کاربری ساده و سبک
- بدون نیاز به حساب کاربری یا ثبت‌نام

دانلود

آخرین نسخه را از صفحه Releases دریافت کنید.

نصب

۱. وارد صفحه Releases شوید.

۲. آخرین نسخه فایل اجرایی NetScope را دانلود کنید.

۳. فایل ".zip" دانلودشده را اجرا کنید.

اگر ویندوز هشدار امنیتی نمایش داد، پیش از ادامه مطمئن شوید که فایل را از مخزن رسمی NetScope دریافت کرده‌اید.

حریم خصوصی

NetScope با در نظر گرفتن حریم خصوصی طراحی شده است.

برای اطلاع از نحوه مدیریت داده‌ها و درخواست‌های شبکه، فایل "سیاست حریم خصوصی" (PRIVACY.md) را مطالعه کنید.

سلب مسئولیت

از NetScope به‌صورت مسئولانه و صرفاً برای اهداف قانونی و مجاز استفاده کنید.

مجوز

اطلاعات مربوط به مجوز نرم‌افزار در به‌روزرسانی‌های آینده اضافه خواهد شد.
